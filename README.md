# Deep-Learning

## ANN(Artifitial Neural Network)-
Built and compared deep learning models for both binary and multi-class classification tasks using TensorFlow/Keras.
* Developed a 5-layer ANN model for Heart Failure Prediction using ReLU activation, achieving an accuracy of approximately 86.1%.

* Performed comparative analysis on the Car Evaluation dataset, where a Multi-Layer ANN achieved 95.6% accuracy, significantly outperforming a linear Perceptron (63.8%), highlighting the importance of non-linear modeling.

* Implemented preprocessing techniques, including Label Encoding, feature scaling, and multi-class handling using Softmax activation and Categorical Cross-entropy loss.

This project demonstrates the effectiveness of deep neural networks over linear models for complex, non-linear datasets


## CNN(Convolutional Neural Network)-
Worked with the MNIST dataset and understood how image data is structured (28×28 pixels) and how labels represent digits (0–9).

* Learned and applied key preprocessing steps like normalization, reshaping data for ANN vs CNN, and one-hot encoding for classification tasks.

* Built three models (Single-layer ANN, Multi-layer ANN, CNN) to understand the difference between simple and deep architectures.

* Observed how model complexity impacts performance and learned why CNN performs better for image data.

* Evaluated and compared all models using accuracy, loss graphs, and visual analysis to understand model behavior and overfitting.
