## Deep-Learning

ANN(Artifitial Neural Network)-
Built and compared deep learning models for both binary and multi-class classification tasks using TensorFlow/Keras.

1. Developed a 5-layer ANN model for Heart Failure Prediction using ReLU activation, achieving an accuracy of approximately 86.1%.

2. Performed comparative analysis on the Car Evaluation dataset, where a Multi-Layer ANN achieved 95.6% accuracy, significantly outperforming a linear Perceptron (63.8%), highlighting the importance of non-linear modeling.

3. Implemented preprocessing techniques, including Label Encoding, feature scaling, and multi-class handling using Softmax activation and Categorical Cross-entropy loss.

This project demonstrates the effectiveness of deep neural networks over linear models for complex, non-linear datasets


CNN(Convolutional Neural Network)-
Worked with the MNIST dataset and understood how image data is structured (28×28 pixels) and how labels represent digits (0–9).

1.Learned and applied key preprocessing steps like normalization, reshaping data for ANN vs CNN, and one-hot encoding for classification tasks.

2.Built three models (Single-layer ANN, Multi-layer ANN, CNN) to understand the difference between simple and deep architectures.

3.Observed how model complexity impacts performance and learned why CNN performs better for image data.

4.Evaluated and compared all models using accuracy, loss graphs, and visual analysis to understand model behavior and overfitting.
